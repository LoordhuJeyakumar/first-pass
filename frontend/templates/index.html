Platform QC rejects film masters that miss a destination’s delivery spec. This checks a master against that spec before you submit.

Values are evaluated from the master's technical metadata against the destination spec. A tested ffmpeg ebur128 adapter (agents/measure.py) measures those values from real media and can generate a master from a media file; the demo masters ship as authored metadata.

streamone.json and hallarc.json are two delivery destinations with independent clause numbering and different targets, so the same master can pass one and fail the other.
